# Share Watcher — releases

Update manifest and installers for Share Watcher. This repository is public so
the application can check for updates without credentials of any kind; the
source code lives in a separate private repository.

- `latest.json` — the current version, its installer URL and SHA-256
- Releases — `ShareWatcher-Setup.exe` for each version

Nothing here is written by hand. The build publishes both.
